Nota de calibración: el ámbar estándar (500/600) es demasiado claro para superar 4.5:1 sobre blanco — por eso el tono de acento en claro es más profundo (#B45309, "amber-700") mientras que en oscuro se usa un ámbar más claro y saturado (#FBBF24). El mismo principio se aplicó al teal, usando #0F766E ("teal-700") en vez de un teal más brillante que fallaba AA sobre fondos claros.

04 — Consistencia entre apps

Tokens semánticos

Cada una de las 14 apps consume los mismos nombres de variable. Solo cambia qué valor de acento se inyecta según la categoría — así el cambio de tema claro/oscuro queda sincronizado en todo el ecosistema.

:root[data-theme="light"]{
  --bg: #FAFAFA;      --surface: #FFFFFF;   --surface-2: #F4F4F5;
  --border: #E4E4E7;  --text: #18181B;      --text-2: #71717A;
}
:root[data-theme="dark"]{
  --bg: #09090B;      --surface: #18181B;   --surface-2: #27272A;
  --border: #3F3F46;  --text: #FAFAFA;      --text-2: #A1A1AA;
}

/* Cada app declara SOLO su acento — el resto hereda del tema global */
[data-category="productivity"][data-theme="light"]{ --accent: #2563EB; }
[data-category="productivity"][data-theme="dark"] { --accent: #60A5FA; }

[data-category="utilities"][data-theme="light"]{ --accent: #0F766E; }
[data-category="utilities"][data-theme="dark"] { --accent: #2DD4BF; }

[data-category="time-math"][data-theme="light"]{ --accent: #B45309; }
[data-category="time-math"][data-theme="dark"] { --accent: #FBBF24; }

Regla práctica: ninguna app fija colores base propios. --bg, --surface, --text, etc. vienen siempre del tema activo del sistema; solo --accent varía, y varía por categoría — no por app individual. Esto garantiza que al pasar de claro a oscuro en cualquiera de las 14 apps, la transición se sienta idéntica y coordinada.
